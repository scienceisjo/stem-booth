검사 결과와 설명, 답변을 함께 볼 수 있어요.

제작대 클리어: 현재 회로 검사 5개 통과 → 설명 기록 → 자기점검 3개 → 완료 버튼. 설명의 내용은 교사가 확인하며, 제작 속도는 점수에 반영하지 않습니다. ‘마지막 연결’은 기기 응답 시각입니다.
