1비트 기억회로

설명 화면 열기 →
  1. 0과 1을 기억하는 한 칸“이 회로는 0 또는 1 하나를 기억해요. 이런 기억 한 칸을 1비트라고 해요. 오늘은 반도체 속 기억 원리를 큰 회로로 만들어 볼 거예요.”
  2. 쓰고, 손을 떼고, 읽어요.“쓰기 버튼을 누르면 전지의 에너지가 축전기에 저장돼요. 쓰기 버튼에서 손을 뗀 뒤 읽기 버튼을 누르면 LED가 빛나죠. 이렇게 1을 기억하고 읽어요.”
  3. 충분히 방전한 뒤 읽으면 0“앞에서 저장한 전하가 남아 있으니 먼저 충분히 방전해요. 이제 읽기 버튼을 눌러도 LED가 꺼져 있죠. 이 상태를 0으로 약속해요.”
  4. 여러 칸을 모으면 숫자가 돼요.“이제 1비트 회로 네 개를 모아 볼게요. 앞에 놓인 숫자 중 불이 켜진 자리만 더해요. 4와 1을 켜면 숫자 5, 신호로는 0101이에요.”
  5. 최종 면접! 비밀 숫자 11“이번에는 비밀 숫자 11이에요. 8, 2, 1 자리를 켜면 1011, 성공이에요! 오늘 만든 것은 반도체 칩 자체가 아니라 DRAM이 기억하는 원리를 보여 주는 모형이에요.”
