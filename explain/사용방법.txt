시작하기
1. 압축 파일 전체를 한 폴더에 풉니다.
2. index.html을 Chrome·Edge·Whale 등 최신 브라우저로 엽니다.
3. 관문에서 원리 설명 또는 장비 조작을 선택합니다. 각 실험의 HTML은 CSS·JS·그림이 모두 내장되어 인터넷 없이 실행됩니다.
4. 다른 기기로 옮길 때는 폴더 전체를 복사하세요. 인터넷 주소로 공개 배포한 상태는 아닙니다.

세계관과 장비 조작
지원자는 6개 입사 관문을 통과하고, 마지막에 로봇 비트에게 합격을 기억시킵니다.
1 게이트봇 / 정문: 손 연결 3곳과 전지 조건에 따른 에너지스틱의 불·소리
2 먼지제로 반장 / 클린룸: 빨대의 전하·거리, 중성 캔의 전하 재배치와 이동
3 깜빡이 / 암실: 형광등을 잡는 손의 위치·거리·전원에 따른 빛의 구간
4 찌릿 기관사 / 터널 열차: 전지 방향·접촉 조건, 열차 운행
4 찌릿 기관사 / 황금 나침반: 전류의 방향·세기·연결에 따른 N극 방향
5 터널지기 할아버지 / 자이로드롭 통로: 관 재질·자석 여부에 따른 낙하 비교
6 소장·비트 / 최종 면접: 1비트 기억 회로에 쓰기 → 손 떼기 → 읽기

상단 ‘과학 시뮬레이터’로 조작 장면에 바로 갑니다(실험 6종은 6쪽, DRAM은 8쪽).
선택상자·슬라이더에 초점이 있을 때 방향키는 해당 조작에 사용됩니다.
초점을 화면 바탕으로 옮기면 방향키로 장면을 넘길 수 있습니다.
플라즈마볼은 받침대에 세우고, 가로 형광등의 긴 유리 면을 구에 대는 배치입니다.
먼 끝을 잡으면 전체가, 가운데를 잡으면 볼과 손 사이가 빛난 관찰을 반영했습니다.
밝기·거리·전자 수·움직임 속도는 원리를 설명하는 모형이며 실측 예측값이 아닙니다.

사용 키
→ / Space : 다음 장
← : 이전 장
Home / End : 처음 / 마지막
R : 현재 장면 다시 재생
T 또는 N : 대본 열기·닫기
O : 전체 장면 선택
숫자 + Enter : 해당 장면 이동
L : 레이저 포인터 켜기·끄기
Esc : 레이저 우선 끄기 / 대본·선택창 닫기
F : 브라우저 전체화면 전환
M : 효과음 음소거·해제
하단 % 버튼 : 효과음 음량 조절
화면 위 동작 줄이기 : 반복·등장 움직임을 줄이고 상태 변화를 바로 표시

레이저는 처음에는 꺼져 있습니다. 켠 뒤 마우스·펜·손가락으로 가리키거나 드래그합니다.
누르는 동안 획이 유지되며, 놓으면 약 1.1초에 걸쳐 사라집니다.
레이저 모드에서는 화면 클릭으로 장면이 넘어가지 않습니다. 방향키나 하단 버튼을 쓰세요.

DRAM 회로 선택
기본: 개선 종이회로 — AA 2개(3V), 2200µF, 쓰기 330Ω, 읽기 1kΩ
선택: 기존 부스 회로 — CR2032(3V), 1000µF, 쓰기 직결, 읽기 220Ω
상단 선택상자로 실제 사용하는 회로를 고르세요. 바꾸면 현재 장면의 조작이 초기화됩니다.
8번째 장에서 쓰기 → 손 떼기 → 읽기를 직접 조작할 수 있습니다.
애니메이션의 시간·밝기는 이해를 위한 표현이며 실제 부품의 측정값을 예측하지 않습니다.
LED가 꺼져도 전압이 정확히 0V인 것은 아닙니다.
실제 DRAM과 만드는 모형의 차이는 9번째 장에서 설명합니다.

운영 팁
각 실험 1분 안팎, 만들기 전 설명 3분 안팎은 연습용 예상 시간입니다.
T 키로 대본을 확인하며 연습하고 방문객에게는 그림과 아래 한 줄을 중심으로 설명하세요.
짧게 설명할 때는 O 키에서 관찰·원리·마지막 정리 장면만 골라도 됩니다.
새 방문객이 오면 Home 키로 처음으로 돌아갑니다.
태블릿·전자칠판은 가로 화면을 권장합니다. 휴대폰 세로 화면은 위아래로 스크롤할 수 있습니다.
현장 전체화면은 브라우저의 F11도 사용할 수 있습니다.
