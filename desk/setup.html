기존 과학이조선생A 프로젝트에 부스 전용 저장 공간을 준비합니다. 접수 화면은 운영 코드로 열고, 손님 화면은 코드 없이 입장 안내를 봅니다.

1. 설치 SQL을 실행해 주세요

아래에서 SQL을 복사하고 프로젝트 A의 SQL Editor에 새 쿼리로 붙여 넣은 뒤 Run을 누릅니다.

프로젝트 A SQL Editor ↗

SETUP.sql 파일 내려받기

이 설치문은 hnr_desk_로 시작하는 부스 전용 항목을 만듭니다. 참가자 테스트 기록은 넣지 않습니다. 다시 실행해도 기존 접수 기록을 초기화하지 않습니다.

2. 결과의 운영 코드를 보관해 주세요

최초 실행 결과에 나오는 운영 코드를 복사해 안전하게 보관하세요. 접수 담당 기기에서만 사용합니다. 손님용 안내문이나 공개 링크에 적지 않습니다.

이 코드는 처음 설치할 때만 표시됩니다. 비밀번호나 Supabase 비밀키를 앱에 입력할 필요는 없습니다.

3. 첫 접수 기기에서 공유를 시작해요

  1. 접수 화면에서 운영 코드를 입력합니다.
  2. 이미 이 기기에 접수한 기록이 있으면 현재 기기 기록으로 공유 시작을 선택합니다.
  3. 첫 운영이라면 빈 시간표로 시작을 선택합니다.

기존 로컬 기록은 자동으로 합치지 않습니다. 처음 공유할 자료를 가진 기기에서 시작하고, 먼저 백업 파일을 보관해 주세요.

변경 사항은 보통 수초 안에 갱신됩니다. 인터넷이 끊기면 새 접수를 잠시 멈추고 연결 상태를 확인해 주세요. 연습 모드는 DB에 저장되지 않습니다.
