선생님을 위한 진행 안내

중학생–고등학생 · 1비트 기본 / 2비트 확장
목표: 쓰기·대기·읽기를 구분하고, 관찰한 근거로 회로를 고치며 DRAM과 모형의 관계를 설명합니다.

수업 전 준비

  • 시제품을 실제 부품으로 완성하고, LED가 읽기에서만 켜지는지 확인합니다.
  • 축전기 1 mF(1000 μF), 220 Ω 저항, 일반 LED를 각 비트당 1개, 누름 스위치를 각 비트당 2개 분배합니다.
  • 학생당 CR2032 3 V 전지·1구 전선형 홀더 각 1개, 도안, 받침, 구리테이프, 투명테이프를 준비합니다.
  • 1비트는 A4 세로 한 장에 2인분, 2·3비트는 A4 가로 한 장에 1인분입니다. 실제 크기 100%로 인쇄합니다.
  • 강의 화면, 가상 제작실, PDF를 교실 기기에서 미리 엽니다. 학생 기기는 가상 제작을 직접 할 때 사용합니다.

90분 기본 수업

도입 10분 → 부품·연결 확인 10분 → 실물 1비트 제작 40분 → 관찰 15분 → 설명·비교 10분 → 정리 5분.

150분 확장 수업

기억과 부품 20분 → 가상 제작 25분 → 휴식·준비 10분 → 실물 제작 65분 → 신호 표현·공유 20분 → 정리 10분. 1비트 작동을 확인한 뒤 2비트로 확장합니다. 제작 상황에 따라 한 칸 완성에 집중해도 좋습니다.

어떤 질문으로 이어 갈까요?

  1. 게임 속 아이템 수가 바뀌면 휴대폰은 무엇을 잠깐 기억해야 할까?
  2. 쓰기에 손을 뗀 뒤에도 읽을 수 있을까?
  3. 불이 안 켜질 때 어떤 연결부터 확인할까?
  4. 계속 읽는 동안 불빛이 달라진 이유는 무엇일까?
  5. 우리 회로와 실제 DRAM은 무엇이 같고 다를까?

DRAM과 연결해 설명하기

대표적인 DRAM 셀은 트랜지스터 하나와 축전기 하나로 이루어집니다. 우리 회로는 큰 축전기에 전하를 저장하고 손으로 쓰기·읽기를 조절해 그 원리를 관찰합니다. 실제 DRAM은 미세한 전압 변화를 감지한 후 값을 복원하고, 주기적으로 리프레시합니다. 우리 LED는 읽는 동안 저장 에너지를 소모합니다.

LED가 꺼져도 남은 전압이 0이라는 뜻은 아닙니다. 빛이 유지되는 시간을 실제 DRAM의 기억 유지 시간으로 설명하지 않습니다. 한 칸은 0 또는 1 하나이고, 숫자나 글자를 표현하려면 여러 칸을 조합해야 합니다.

증상별 빠른 점검

  • 전혀 안 켜짐: 전지·전원 → LED·축전기 극성 → 접촉 → 스위치 내부 묶음.
  • 계속 켜짐: 스위치 틈을 구리가 덮었는지, 항상 연결된 다리를 사용했는지.
  • 쓰는 동안만 켜짐: 축전기의 DATA·GND 접촉과 극성.
  • 두 칸이 같이 반응: 두 DATA의 연결, 불필요한 우회 배선.

관찰과 피드백

완성 여부와 함께 ‘예상한 것, 관찰한 증거, 바꾼 연결, 실제 DRAM과의 비교’를 확인합니다. 가상 제작 시간과 불빛은 설명용 모형입니다. 이 자료 모음에서는 학생 답변을 온라인으로 수집하지 않습니다.

전원 관리

수정 전에는 전원을 끕니다. 전해 축전기 극성을 확인하고 전지 +와 −를 바로 잇지 않습니다. 열이 나면 즉시 분리합니다. 동전전지를 삼키지 않도록 관리하고 수업 후 전원을 끕니다.
