오프라인 실험 자료 사용방법 (2026.10.23)

1. HNR_TECH_offline.zip을 노트북에 저장합니다.
2. ZIP의 모든 파일을 한 폴더에 압축 해제합니다.
3. 압축을 푼 폴더의 index.html을 Chrome 또는 Edge로 엽니다.
4. 실험별 '조작'을 기본으로 열어 두고, 방문객에 맞게 '하' 또는 '상' 탭을 보여 줍니다.
5. 소리는 버튼을 한 번 누른 뒤 재생됩니다. F: 전체화면, 방향키: 설명 이동.

자료는 총 21개입니다.
- 실험 6종 × 하/상/조작 = 18개
- 진행자 대본 하/상 = 2개
- 8421 최종 면접 = 1개
index.html은 이 자료들을 여는 시작 화면입니다.

각 HTML에는 그림, 스타일, 코드가 들어 있어 인터넷 없이 사용할 수 있습니다.
개별 HTML 하나만 옮겨도 해당 자료는 작동합니다.
하/상 전환과 대본 등 자료 간 이동을 하려면 전체 파일을 같은 폴더에 보관하세요.
연구소 맵, 접수·예약 공유, 인생네컷은 이 묶음에 포함하지 않습니다.
과학 참고자료 외부 링크는 인터넷이 필요합니다.
ZIP 안의 파일을 바로 열지 말고 압축 해제 후 열어 주세요.
