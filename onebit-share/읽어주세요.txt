2. 02 매뉴얼 PDF: A4 세로 / 양면 / 긴 쪽 넘기기 / 총 2쪽
3. 03_수업진행/index.html: 제작 중심 수업 허브. 제작 강의·회로 도안·매뉴얼 연결
4. 04 설명: PDF·HTML·TXT 제공
5. 05 구매 링크: HTML·TXT 제공, 핵심 부품 5종, G마켓

수업 흐름
작동 살펴보기 → 재료 확인 → 회로 만들기 → 작동 점검 → 정리

강의 조작: ← → 단계 이동 / N 원고 / R 다시 / F 전체 화면 / L 레이저
실제 제작은 1비트. 강의 4~7쪽의 2비트 예시는 정보 표현 도입입니다.

교실 준비
1인당 1000μF 축전기·220Ω 저항·LED 각 1개, 누름 스위치 2개, CR2032 3V·홀더 각 1개.
도안 받침, 폭 10mm 구리테이프, 고정테이프와 가위를 준비합니다.

파일 사용
폴더 구조를 유지해 주세요. 강의 HTML에는 글꼴·SVG·스크립트가 포함되어 있습니다.
인터넷이 없으면 03_수업진행/자료 폴더의 강의 HTML·디지털 모형을 열 수 있습니다.
전체 허브의 이어보기는 브라우저 보안 정책에 영향을 받을 수 있습니다. 문제가 있으면 자료 폴더의 강의 HTML을 직접 열거나 아래의 로컬 실행 방법을 사용하세요.
고급 로컬 실행: 이 폴더에서 python -m http.server 7158 --bind 127.0.0.1

도안 원본의 크기와 선 위치는 보존하고 두 회로 각각 아래 여백에 제작자 이름을 추가했습니다.
매뉴얼의 그림은 SVG 원본도 함께 제공합니다.
구매 링크는 확인 당시 상품명·규격 기준이며 가격·재고·배송 보장은 아닙니다.
